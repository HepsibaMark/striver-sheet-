# Striver's SDE Sheet & Coding Solutions 🚀

Welcome to my repository! This project contains my personal solutions to popular coding interview sheets and data structures & algorithms (DSA) practice problems, inspired by **Striver's SDE Sheet** and other top interview preparation guides. 

The goal of this repository is to keep track of my problem-solving journey, optimize solutions for better time and space complexity, and serve as a quick revision guide for coding interviews.

---

## 🛠️ Topics Covered

This repository includes solutions to problems across various core computer science and data structure topics:

- **Arrays & Matrices:** Kadane's Algorithm, Two Pointers, Sliding Window, Matrix Manipulation
- **Strings:** Pattern Matching, Anagrams, Palindromes, String Manipulation
- **Linked Lists:** Reversal, Cycle Detection, Merging, LRU Cache
- **Recursion & Backtracking:** N-Queens, Sudoku Solver, Subsequences
- **Staircase / Dynamic Progression (DP):** 1D/2D DP, Knapsack, LCS, DP on Grids & Trees
- **Trees & Binary Search Trees (BST):** Traversals, Views, LCA, Balanced BSTs
- **Graphs:** BFS, DFS, Dijkstra, Minimum Spanning Trees (Kruskal's/Prim's), Topological Sort
- **Trie & Heaps / Priority Queues:** Prefix Tree, Median Finder, Kth Largest Element
- **Greedy Algorithms & Binary Search**
- **SQL Queries & Database Management**
